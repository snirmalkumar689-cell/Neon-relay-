# NEON RELAY — Signal Runner

A small original browser arcade game built with plain HTML, CSS and JavaScript. No frameworks, build tools, dependencies, or external assets are required.

## Run locally
Open `index.html` in any modern browser.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` (and this README).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site. Your game URL will appear in the Pages section.

## Controls
- Move: Arrow keys or WASD
- Pause/resume: P or Escape
- Mobile: on-screen directional pad
- Collect all 5 cyan data cells, then enter the gold relay gate.
- Avoid pink sentries. Complete sectors to increase the difficulty.

Made with vanilla HTML, CSS and JavaScript.
